# shree-goga-medi-app
Official project repository for Shree Goga Medi Dham – Jamniwala Darbar App

🙏 Shree Goga Medi Dham – Jamniwala Darbar App


A modern devotional mobile application designed to connect devotees with Shree Goga Medi Dham – Jamniwala Darbar through digital services, spiritual content, and convenient access to temple-related information.

✨ Key Features

- 🛕 Home Dashboard: Access important devotional services from one place.
- 📺 Live Darshan: A dedicated section for live spiritual experiences.
- 🙏 Puja Services: Access information about puja-related services.
- 🚌 Yatra Management: A dedicated section for pilgrimage information and booking features.
- 📜 Parcha System: A dedicated interface for private spiritual guidance.
- 📅 Panchang & Calendar: Access religious dates and temple events.
- 🎵 Bhajans & Chalisa: A dedicated section for devotional music and spiritual reading.
- 📰 Daily Suvichar: Spiritual thoughts for daily inspiration.
- 👤 User Profiles: A dedicated profile experience for devotees.
- 🌐 Multilingual Support: Designed for English and Hindi users.
- 🔔 Notifications: Support for important updates and announcements.
- ⚙️ Admin Management: Planned administrative tools for managing app content and services.

🛠️ Technology Stack

- Programming Language: Kotlin
- UI Framework: Compose Multiplatform
- UI Components: Material Design 3
- Architecture: MVVM
- Asynchronous Programming: Kotlin Coroutines and Flow
- Data Serialization: Kotlinx Serialization
- Build System: Gradle with Kotlin DSL
- Current Data Storage: Local JSON persistence, where implemented
- Future Backend Integration: Firebase / Cloud Firestore

«Note: The technology and feature lists describe the intended project architecture. Availability of individual features and integrations depends on the current implementation.»

🚀 Getting Started

Prerequisites

- Android Studio
- Compatible JDK
- Android SDK
- Gradle wrapper included in the repository

Run the Project

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Connect an Android device or start an emulator.
5. Run the app using Android Studio.

Alternatively, on Windows, open the project directory in a terminal and run:

.\gradlew.bat assembleDebug

The build may require SDK configuration and compatible development tools.
